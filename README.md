# 🎨 Kendra Martinez - Portfolio de Diseño Gráfico

Un portfolio web profesional, moderno y optimizado para SEO, creado para exhibir los trabajos de identidad visual, branding, contenido para redes sociales y diseño editorial de Kendra Martinez (Diseñadora Gráfica Junior).

🌐 **Sitio en vivo:** [martinezkendra.github.io](https://martinezkendra.github.io/)

## ✨ Características Principales (Features)

- **Diseño 100% Responsivo:** Adaptable a dispositivos móviles, tablets y pantallas grandes.
- **Animaciones "Scroll Reveal":** Elementos que aparecen suavemente a medida que el usuario baja por la página (sin librerías externas, usando `IntersectionObserver`).
- **Galería Interactiva (Lightbox):** Visualización de los proyectos de diseño en pantalla completa al hacer clic.
- **Optimización SEO & Rendimiento:** 
  - Etiquetas Meta, Open Graph (Facebook/LinkedIn) y Twitter Cards configuradas.
  - Datos Estructurados (JSON-LD - Schema.org) para mejorar el posicionamiento en Google.
  - Carga asíncrona de imágenes y pre-conexión de fuentes.
- **Descarga de CV:** Botón directo para descargar el currículum en formato PDF.

## 🛠️ Tecnologías Utilizadas

- **HTML5** (Semántico y Accesible)
- **CSS3** (Estilos nativos, Flexbox, CSS Grid)
- **JavaScript (Vanilla)** (Lógica para el Lightbox, navegación suave y animaciones)
- **FontAwesome** (Iconografía)
- **Google Fonts** (Inter & Montserrat)
